## Маршруты

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/` | Перенаправление на `/courses` |
| GET | `/courses` | Список курсов, поиск `?search=` и фильтр `?semester=` |
| GET | `/courses/new` | Форма добавления |
| POST | `/courses` | Сохранение нового курса |
| GET | `/courses/:id` | Страница одного курса |
| GET | `/courses/:id/edit` | Форма редактирования |
| POST | `/courses/:id/edit` | Сохранение изменений |
| POST | `/courses/:id/delete` | Удаление курса |

## Что было сделано

1. **MVC.** В `app.js` только настройки и подключение маршрутов. Маршруты лежат в `routes`, логика — в `controllers`, массив курсов — в `models`.
2. **EJS.** Подключён через `app.set('view engine', 'ejs')`. Шапка и подвал вынесены в `partials` и подключены на всех страницах через `include`.
3. **Формы.** Данные читаются через `express.urlencoded()` из `req.body`.
4. **ID нового курса** считается автоматически: максимальный ID + 1.
5. **Поиск и фильтр.** Поиск идёт по названию и по преподавателю без учёта регистра (`toLowerCase` + `includes`). Семестр выбирается из списка `<select>`. Оба условия можно использовать вместе.
6. **Валидация.** Middleware `validateCourse` проверяет все поля. Если есть ошибки, курс не сохраняется, форма показывается снова с сообщениями и уже введёнными данными (код ответа `400`).
7. **Удаление.** Сделано через форму с методом POST и подтверждением `confirm()`.
8. **Логирование.** Middleware `logger` подключён до маршрутов и пишет в терминал метод, адрес, дату и время.
9. **Ошибки.** Страница `404.ejs` показывается для неизвестного адреса и для несуществующего курса, на ней виден запрошенный URL. Страница `error.ejs` показывается при внутренней ошибке, stack trace пользователю не выводится.
10. **CSS.** Оформлены навигация, таблица, формы, сообщения об ошибках. Кнопки «Просмотр», «Редактировать» и «Удалить» разного цвета.

## Результаты проверки

| Запрос | Результат |
| --- | --- |
| `GET /` | `302` → `/courses` |
| `GET /courses` | `200`, таблица из 5 курсов |
| `GET /courses?search=IVAN&semester=1` | `200`, найден 1 курс |
| `GET /courses?search=zzz` | `200`, сообщение «Курсы не найдены» |
| `GET /courses/2` | `200` |
| `GET /courses/99` | `404` |
| `GET /nope` | `404`, на странице показан адрес `/nope` |
| `POST /courses` с пустым названием, кредитами `-1`, семестром `9` | `400`, три сообщения об ошибках, введённые данные остались в форме |
| `POST /courses` с правильными данными | `302` → `/courses` |
| `POST /courses/6/edit` | `302` → `/courses/6` |
| `POST /courses/6/delete` | `302` → `/courses` |
| `POST /courses/6/delete` ещё раз | `404` |
